Q2. What is a Cell, Cell Address, Workbook, and Worksheet in Excel?

Definitions with examples

  • 1
    Cell: Smallest unit of a worksheet. Located at the intersection of a row and a column. Stores text, numbers, or formulas. Example: Cell A1 contains "Name".
  • 2
    Cell Address: Unique identifier of a cell — column letter + row number. Example: B3 = Column B, Row 3. Think of it like coordinates (latitude + longitude).

  • 5
    Range: A group of cells. Example: A1:C5 refers to all cells from A1 to C5 (15 cells total).

Q5. Explain Formulas vs Functions in Excel. Explain the order of operations (PEDMAS). Give examples.
8 Marks🔥 Hot
▼

Formula vs Function

FormulaFunction
User-defined equation that starts with =Pre-built, named calculation built into Excel
Manually typed every timeCalled by name with arguments in parentheses
More flexible but tedious for complex tasksFaster, less error-prone, handles complex logic
Example: =A1+A2+A3Example: =SUM(A1:A3)

Order of Operations — PEDMAS

Excel evaluates formulas in this order:
  • P
    Parentheses — calculated first. Example: =(2+3)*4 = 20
  • E
    Exponentiation — power of. Example: =2^3 = 8
  • D
    Division — left to right with multiplication
  • M
    Multiplication — left to right with division
  • A
    Addition — left to right with subtraction
  • S
    Subtraction — last
Example: =5+3*2 → 5 + 6 = 11 (NOT 16, because * comes before +) Example: =(5+3)*2 → 8*2 = 16 (parentheses evaluated first)

Common Functions (mention at least 8 for 8 marks)

  • =SUM(A1:A10) — adds all values
  • =AVERAGE(A1:A10) — arithmetic mean
  • =COUNT(A1:A10) — counts numeric cells
  • =COUNTA(A1:A10) — counts all non-empty cells
  • =MAX(A1:A10) — largest value
  • =MIN(A1:A10) — smallest value
  • =IF(A1>50,"Pass","Fail") — logical test
  • =VLOOKUP("Apple",A1:C10,2,FALSE) — lookup value
  • =CONCATENATE("Hello"," ","World") — merge text → "Hello World"
  • =TRIM(" Excel ") — removes extra spaces → "Excel"

Q1. Explain VLOOKUP and XLOOKUP functions with syntax and examples.
5 Marks🔥 Hot
▼

VLOOKUP — Vertical Lookup

Searches for a value in the first (leftmost) column of a table and returns a value from another column in the same row.
=VLOOKUP(value, table_array, col_index_num, [range_lookup]) Arguments: value → What to search for (e.g., "Apple" or A2) table_array → The data table range (e.g., A1:D100) col_index → Column number to return (1=first col, 2=second, etc.) range_lookup → FALSE = exact match | TRUE = approximate match Example: =VLOOKUP("Apple", A1:C10, 2, FALSE) → Finds "Apple" in column A, returns value from column B

XLOOKUP — Improved Lookup (modern)

=XLOOKUP(lookup_value, lookup_array, return_array) Example: =XLOOKUP("Apple", A1:A10, B1:B10) → Searches column A for Apple, returns matching value from column B Advantages over VLOOKUP: - Can search in ANY direction (left, right, up, down) - Returns entire row/column (array) - Handles errors gracefully with [if_not_found] argument

Limitations of VLOOKUP

  • Can only look from left column to the right (cannot look left)
  • If a column is inserted/deleted, column index number breaks
  • Slower on very large datasets compared to INDEX-MATCH
Q2. Explain INDEX and MATCH functions. Why use INDEX-MATCH over VLOOKUP?
8 Marks🔥 Hot
▼

INDEX Function

=INDEX(array, row_num, [col_num]) → Returns the value at a specific row and column position Example: =INDEX(A1:C10, 3, 2) → Returns value in row 3, column 2 of range A1:C10

MATCH Function

=MATCH(lookup_value, lookup_array, [match_type]) → Returns the POSITION (row number) of a value in a range Example: =MATCH("Apple", A1:A10, 0) → Returns 3 if Apple is in row 3 match_type: 0 = exact match

Combined INDEX-MATCH Formula

=INDEX(B1:B10, MATCH("Apple", A1:A10, 0)) How it works: 1. MATCH finds the row where "Apple" exists in column A → returns position (e.g., 3) 2. INDEX uses that position to return the value from column B → returns B3

Why INDEX-MATCH is better than VLOOKUP

FeatureVLOOKUPINDEX-MATCH
DirectionLeft to right onlyAny direction
Column insertionBreaks formulaNot affected
Speed on large dataSlowerFaster
FlexibilityLimitedVery flexible
Error riskHigherLower

Definition

A Macro is a recorded series of steps (actions) that can be replayed with a single click to automate repetitive tasks. Macros are stored as VBA (Visual Basic for Applications) code inside the Excel file. They save time and reduce human error.

Macro Languages in Excel

  • VBA (Visual Basic for Applications): Current standard — used in all modern Excel versions. Requires basic programming knowledge to edit.
  • XLM: Old macro language from Excel 4.0. Deprecated and disabled in modern Excel for security reasons.

  • 3
    Click OK — recording begins. Every action you take is now recorded.
  • 4
    Perform the actions you want to automate (e.g., bold headers, apply borders, sort data)
  • 5
    Click Stop Recording (View → Macros → Stop Recording)
  • 6
    Save the file as .xlsm (Macro-Enabled Workbook)

Steps to Run a Macro

  • 1
    View tab → Macros → View Macros → select macro → click Run
  • 2
    OR use the assigned keyboard shortcut (e.g., Ctrl+Shift+F)
  • 3
    To edit: View → Macros → Edit → opens VBA editor (Alt+F11)

Q3. Explain What-If Analysis in Excel — Goal Seek, Scenario Manager, and Data Tables.
8 Marks🔥 Hot
▼

Definition

What-If Analysis is the process of changing values in cells to see how those changes affect the outcome of formulas. It is used for scenario planning, forecasting, and decision-making. Found at: Data tab → What-If Analysis.

1. Goal Seek

Used when you know the desired result but don't know the input value needed to achieve it.
Example: You want ₹1,00,000 profit. Your profit formula is in C5. You don't know how many units to sell. Steps: Data → What-If Analysis → Goal Seek Set Cell: C5 (profit formula) To Value: 100000 By Changing Cell: B5 (units sold) → Click OK → Excel calculates required units automatically

2. Scenario Manager

Create, save, and compare multiple named scenarios (sets of input values).
Example: Compare Best Case vs Worst Case vs Base Case sales Data → What-If Analysis → Scenario Manager → Add Name: "Best Case" | Changing cells: B2 (units), C2 (price) Enter values → OK Add more scenarios → click "Summary" to see a comparison report

3. Data Tables

Shows results of multiple input values at once — used in financial modeling.
One-Variable Data Table: Column of input values → reference formula at top-right Select range → Data → What-If → Data Table Set "Column input cell" → OK → Results for each input appear automatically

Q1. What is SmartArt? How do you add and modify it in PowerPoint?
5 Marks🔥 Hot

Definition

SmartArt is a visual diagram tool in PowerPoint used to represent information in a structured, graphical way — such as organizational charts, process flows, hierarchies, cycles, and relationship diagrams. It is much more visually appealing than plain bullet points.

Steps to Insert SmartArt

  • 1
    Insert tab → SmartArt
  • 2
    Choose a category: List, Process, Cycle, Hierarchy, Relationship, Matrix, Pyramid
  • 3
    Select a design → Click OK
  • 4
    Click on text placeholders to type your content
  • 5
    Use SmartArt Design tab to change layout, colors, style

Common SmartArt Types

  • Hierarchy: Org charts — boss → managers → employees
  • Process: Step-by-step flows — Step1 → Step2 → Step3
  • Cycle: Repeating processes — Plan → Do → Check → Act
  • List: Visual bullet points with icons
  • Relationship: Venn diagrams, overlapping ideas

Scenario 1: Sales Performance Analysis (Most Likely)
14 Marks🔥 Hot
▼

The Question

A company tracks monthly sales across departments. The dataset has columns: Department (A), Month (B), Sales Amount (C), Target (D), Status (E — "Met" / "Not Met"). Management wants Excel analysis and a PowerPoint report.
Part A — Excel Analysis (7 Marks)

Task 1: Total Sales by Department using SUMIF

=SUMIF(A:A, "Marketing", C:C) → Adds all sales amounts in column C where column A = "Marketing" For all departments, use SUMIFS for multiple criteria: =SUMIFS(C:C, A:A, "Marketing", D:D, "Q1") → Total Marketing sales in Q1 only

Task 2: Average Sales per Department using AVERAGEIF

=AVERAGEIF(A:A, "Sales", C:C) → Average of C column where column A = "Sales"

Task 3: Count departments that met target using COUNTIF

=COUNTIF(E:E, "Met") → How many rows have Status = "Met" =COUNTIF(E:E, "Not Met") → How many missed target

Task 4: Highlight underperforming rows using Conditional Formatting

  • 1
    Select column C (Sales Amount)
  • 2
    Home → Conditional Formatting → New Rule → "Use formula"
  • 3
    Enter: =C2<D2 (where sales is below target)
  • 4
    Set red fill → OK

Task 5: Create a PivotTable + Column Chart

  • 1
    Select data → Insert → PivotTable → New Sheet
  • 2
    Drag Department to Rows, Sales Amount to Values (Sum), Month to Columns
  • 3
    PivotTable Analyze → PivotChart → Column Chart → shows department-wise monthly comparison
Part B — PowerPoint Design (7 Marks)

5-Slide Deck Design with Slide Master and Navigation

  • 1
    Slide Master Setup: View → Slide Master → set company logo (top-right corner), brand font (e.g., Calibri), background color → Close Master View → applies to all 5 slides automatically
  • 2
    Slide 1 (Home/Menu): Title: "Sales Performance Report Q1 2025". Insert 4 rectangle shapes labeled: Marketing | Sales | IT | Operations. Link each shape to its respective slide using Ctrl+K → Place in This Document
  • 3
    Slides 2–5 (Department slides): Each contains: Department heading, Paste the Excel chart (Paste Special → Linked), key metrics (Total, Average, Status count), 2-3 bullet point insights
  • 4
    Return to Home Button: View → Slide Master → Insert → Shapes → Action Buttons → Home icon → draw button → Set "Hyperlink to: First Slide" → OK. This adds the button on ALL slides from one place
  • 5
    Transitions: Apply a consistent Fade transition to all slides: Transitions tab → Fade → Apply to All
Full marks tip: Write SUMIF formula + AVERAGEIF formula + Conditional Formatting steps + PivotTable steps for Part A. For Part B: Slide Master setup + Home slide hyperlinks + Action Button on Slide Master + transitions. Explain each clearly.
Scenario 2: Student Gradebook / HR Employee Data
14 Marks
▼

The Question

A teacher has student data: Roll No (A), Name (B), Midterm Score (C, weighted 40%), Final Exam Score (D, weighted 60%), Attendance % (E). Weights are stored in H1 (0.4) and H2 (0.6).
Part A — Excel (7 Marks)

Formula 1: Weighted Grade in Column F

=(C2*$H$1)+(D2*$H$2) → Multiplies midterm by 40% weight (H1) and final by 60% weight (H2) → Absolute reference ($H$1) ensures weights don't shift when formula is copied down → Drag formula from F2 to F30 for all students

Formula 2: Pass/Fail in Column G using IF + AND

=IF(AND(F2>=60, E2>=75), "Pass", "Fail") → AND checks BOTH conditions must be true: F2>=60 → weighted grade 60 or above E2>=75 → attendance 75% or above → IF both true → "Pass", otherwise → "Fail"

Formula 3: Count of Pass/Fail students

=COUNTIF(G2:G30, "Pass") → Number who passed =COUNTIF(G2:G30, "Fail") → Number who failed

Formula 4: Class Average using AVERAGE

=AVERAGE(F2:F30) → Class average of weighted grades =MAX(F2:F30) → Highest score =MIN(F2:F30) → Lowest score

Conditional Formatting: Highlight failing students red

Select G2:G30 → Home → Conditional Formatting → Highlight Cell Rules → Equal To → "Fail" → Red fill → OK
Part B — PowerPoint (7 Marks)

Academic Report Presentation — 5 Slides

  • 1
    Slide Master: View → Slide Master → add school logo, choose professional theme (blue/white), set consistent font. Add slide number placeholder via Insert → Slide Number → Apply to All. Close Slide Master.
  • 2
    Slide 1 — Home Slide: "Student Performance Report 2025". Buttons: Overview | Grade Distribution | Pass/Fail Analysis | Recommendations. Link each to its slide.
  • 3
    Slide 2 — Overview: Summary table (copy from Excel), class average, highest and lowest scorer highlighted.
  • 4
    Slide 3 — Grade Distribution: Insert Bar Chart (from Excel) showing grade ranges — A, B, C, D, F. Add animation: Wipe effect, one bar at a time (On Click).
  • 5
    Slide 4 — Pass/Fail: Pie Chart (only 2 categories — Pass vs Fail) + COUNTIF numbers. Use SmartArt for recommendations.
  • 6
    Slide 5 — Recommendations: 4-5 bullet points using SmartArt List.
  • 7
    Return Button on ALL slides: View → Slide Master → Insert Action Button (Home) → Hyperlink to First Slide → Close Master.
